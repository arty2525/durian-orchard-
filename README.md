# Durian Orchard — ระบบบริหารสวนทุเรียน

ซอร์สโค้ดระบบบริหารสวนขนาด 8 ไร่ (บน 5 ไร่ / ล่าง 3 ไร่) เป้าหมาย 400 ต้น พร้อม QR ตรวจสอบย้อนกลับ

## สถานะ

Repository นี้เก็บโค้ดรุ่นที่เผยแพร่แล้ว ไม่ได้เปิดเว็บหรือย้ายข้อมูลจริงโดยอัตโนมัติ
เว็บที่ใช้งานอยู่: https://durian-orchard-art.siwat-t36.chatgpt.site
ข้อมูลสวนจริง รูปภาพ และค่าลับไม่ได้รวมอยู่ใน Repository นี้

## ความสามารถ

- ทะเบียนต้น รหัสอัตโนมัติ D0001 เป็นต้นไป รองรับหลายคนเพิ่มพร้อมกัน และไม่ใช้รหัสที่ลบซ้ำ
- พื้นที่บน–ล่าง พันธุ์ วันปลูก ปีเริ่มให้ผล และข้อมูลย้อนหลังที่ทราบเฉพาะปี
- ทะเบียนผล เชื่อมต้นแม่ ฤดูกาล วันที่ติดผล สถานะ น้ำหนัก และคุณภาพ
- QR ประจำต้นและผล พิมพ์เป็นป้ายหรือบันทึก PDF ผ่านหน้าต่างพิมพ์
- บันทึกรดน้ำ ปุ๋ย ตัดแต่ง และสุขภาพต้น ทั้งรายต้นและรายพื้นที่
- แนบรูปจากอุปกรณ์หรือกล้อง พร้อมเลือกวันที่จากปฏิทิน
- ทีมงาน 5 คน แอดมิน และหน้าลูกค้าแบบอ่านอย่างเดียว
- ประวัติการแก้ไขและส่งออกข้อมูล JSON (ไม่รวมไฟล์ภาพ)

## เทคโนโลยี

TypeScript / React / Vinext, Cloudflare Workers, D1 (SQLite), R2 และ Drizzle migrations
รูปภาพจัดเก็บใน R2; ข้อมูลทะเบียนและสิทธิ์ทีมงานจัดเก็บใน D1

## ติดตั้งและตรวจสอบ

ต้องใช้ Node.js 22.13+ และ pnpm 11 ตาม lockfile

```sh
pnpm install --frozen-lockfile
pnpm exec tsc --noEmit
node scripts/test-server.mjs
node scripts/test-record-inputs.mjs
pnpm build
```

ดู `docs/MIGRATION.md` ก่อนเผยแพร่ภายนอก GitHub Pages ไม่สามารถรัน API และฐานข้อมูลของแอปนี้โดยตรง

## การยืนยันตัวตนและสิทธิ์

เว็บปัจจุบันใช้ ChatGPT sign-in ผ่าน Sites โดยตรวจ identity headers ที่แพลตฟอร์มยืนยันแล้ว
OWNER_EMAIL และ ADMIN_EMAILS เป็นค่า server-side ของเว็บปัจจุบัน ไม่ได้บันทึกในโค้ด
การวางบนโฮสต์อื่นต้องเปลี่ยนการยืนยันตัวตนให้เหมาะกับโฮสต์ก่อนเปิดใช้งาน
ห้ามเชื่อถือ identity headers ที่ผู้เรียกส่งเองโดยไม่มี gateway ตรวจสอบ
