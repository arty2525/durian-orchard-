# แผนย้ายโฮสต์ระบบสวน

## ส่วนที่ย้ายมาที่ GitHub แล้ว

โค้ดหน้าเว็บ API, schema, migrations และชุดทดสอบ
ไฟล์ `.openai/hosting.json` เอา project_id ของเว็บเดิมออก เพื่อป้องกัน deploy ทับเว็บเดิมจาก checkout ใหม่นี้

## ส่วนที่ยังอยู่บนระบบเดิม

- เว็บจริงและลิงก์ QR ที่เผยแพร่แล้ว
- ฐานข้อมูล D1 และไฟล์รูป R2
- ค่า OWNER_EMAIL / ADMIN_EMAILS และการลงชื่อเข้าใช้ ChatGPT ผ่าน Sites

## ขั้นตอนก่อนย้ายเว็บจริง

1. เลือกบัญชีโฮสต์ที่รัน Workers/แอป Vinext ได้ และสร้าง D1 กับ R2 ปลายทาง
2. ตั้งค่าการ build/deploy และผูก DB กับ BUCKET; แยก environment ทดสอบก่อน production
3. เปลี่ยน ChatGPT/Sites auth เป็นระบบยืนยันตัวตนที่โฮสต์ใหม่รองรับ พร้อมตรวจสิทธิ์ API ฝั่งเซิร์ฟเวอร์ทุกครั้ง
4. สำรองและย้าย D1 ทั้ง records, audit, counters และ migration history; ย้ายวัตถุ R2 โดยคง key เดิม
5. ตั้งค่าแอดมินและทดสอบเจ้าของ ทีมงาน ลูกค้า anonymous และบัญชีที่ไม่มีสิทธิ์
6. ตรวจรหัสต้นถัดไป การอัปโหลดภาพจากมือถือ การแก้ไขพร้อมกัน และหน้าประวัติลูกค้า
7. กำหนดโดเมนระยะยาวและวิธีคงการเปิด QR เดิม; QR ที่พิมพ์แล้วผูกกับ origin ของเว็บเดิม
8. สลับระบบหลังตรวจความครบถ้วนของข้อมูลและภาพ พร้อมเก็บช่องทางกลับไปเว็บเดิม

การอัปโหลดโค้ดลง Repository นี้ยังไม่เท่ากับทำขั้นตอนทั้งหมดข้างต้นเสร็จ
อย่าเปิด GitHub Pages แล้วคาดว่า API /api/data และ /api/photo จะทำงานเอง
