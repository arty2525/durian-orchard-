# จัดการด่วนและค่าเริ่มต้น

เปิดหน้าภาพรวม ทะเบียนต้น ผล หรือการดูแล จะพบแถบจัดการด่วน ไม่ต้องเปิดหน้ารายต้นเพื่อใช้ข้อมูลเดียวกันหลายรายการ

- ปุ๋ยและแผนดูแล: กรอกสูตร ปริมาณต่อต้น และวันที่ เลือกทั้งสวน โซนบน A–G โซนล่าง รายการในหน้า หรือรายการที่ติ๊กไว้ แล้วใช้กับหลายต้นพร้อมกัน เริ่มต้นเป็นแผนก่อน ผู้ใช้เอาเครื่องหมายแผนออกเพื่อยืนยันว่าใส่จริงแล้วได้
- ค่าเริ่มต้นของผล: เลือกฤดูกาล ใส่วันที่คาดว่าจะเก็บเกี่ยว น้ำหนักและขนาดประมาณการ ใช้กับผลเดิม หรือจำเป็นค่าเริ่มต้นของผลใหม่ทั้งสวนในฤดูกาลนั้นได้
- เก็บเกี่ยวจริง: เลือกฤดูกาลและวันที่จริง ยืนยันก่อนบันทึก ระบบใช้เฉพาะผลที่กำลังเติบโตและยังไม่มีวันเก็บเกี่ยวจริง

ช่องจริงและช่องประมาณการเก็บแยกกัน ค่าเริ่มต้นไม่เปลี่ยนสถานะผล ไม่หยุดรอบถ่ายภาพ 14 วัน และไม่ทับน้ำหนัก ขนาด หรือวันเก็บเกี่ยวจริงเดิม การปรับแต่ละผลใช้ปุ่มแก้ไขจากรายการได้เลย

ปุ่มบันทึกค่าเริ่มต้นอย่างเดียวไม่สร้างกิจกรรมใส่ปุ๋ย ไม่สร้างผล และไม่เปลี่ยนข้อมูลต้นเดิม ข้อมูลการใช้หลายรายการเก็บประวัติผู้แก้ไขและรายชื่อต้น ณ วันที่บันทึก

ไฟล์ database/quick-actions.sql เป็นขั้นตอนอัปเกรดฐานข้อมูลที่ใช้เพิ่มความสามารถนี้ ส่วน database/test-quick-actions.sql ทดสอบใน transaction และ rollback ทั้งหมด
